# Misty

A self-hosted personal assistant stack with conversation archiving and laptop tools.

- **Misty:** an assistant with memory, reminders, scheduled tasks and owner-authorized computer work
- **Apollo:** a quiet inbox for relevant findings from selected conversations
- **Archival:** a web interface for conversation history, search, summaries and connected accounts
- **Supporting tools:** Discord and WhatsApp collectors, account integrations, laptop and browser bridges, a Windows overlay, voice support, service metrics and deployment scripts

Source, assets, synthetic tests and supporting documentation are included. Personal data, credentials and production history are excluded.

To run it, ask Claude or Codex to hook it up for your own accounts and machine. Working with a coding agent is also how this stack is intended to be extended and maintained—get used to it.
