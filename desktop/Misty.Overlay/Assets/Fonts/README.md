# Bundled chat fonts

These unmodified fonts are embedded in the Misty overlay so the chat font
picker works without installing fonts system-wide. Each font's `OFL.txt` is
copied beside the published executable under `Assets/Fonts/<family>/`.

| Picker name | Source | License |
| --- | --- | --- |
| Inter | [Google Fonts Inter](https://github.com/google/fonts/tree/main/ofl/inter) | SIL Open Font License 1.1 |
| Roboto | [Google Fonts Roboto](https://github.com/google/fonts/tree/main/ofl/roboto) | SIL Open Font License 1.1 |
| IBM Plex Sans | [Google Fonts IBM Plex Sans](https://github.com/google/fonts/tree/main/ofl/ibmplexsans) | SIL Open Font License 1.1 |
| Source Sans 3 | [Adobe Source Sans, release branch](https://github.com/adobe-fonts/source-sans/tree/release/TTF) | SIL Open Font License 1.1 |
| Mona Sans | [GitHub Mona Sans](https://github.com/github/mona-sans/tree/main/fonts/static/ttf) | SIL Open Font License 1.1 |

Whitney Book remains a local system font option and is not bundled.
